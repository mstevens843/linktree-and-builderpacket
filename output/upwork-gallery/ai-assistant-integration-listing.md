FAQ:
1. Will this work with my existing app?
This package fits an existing React frontend with a working Node.js or Python backend. It reuses your app's authentication where needed. Send your stack and use case before ordering. Other stacks or a new app need separate scope.

2. Can the assistant use my business information?
Yes. Choose one supplied FAQ document of up to 3,000 words or one existing read-only API endpoint. Document uploads, website crawling, vector search, multiple sources, and building a new data API require separate scope.

3. Can it take actions, and will every answer be correct?
This package reads information and returns answers. Bookings, payments, record changes, and approval workflows need separate scope. I test 10 agreed cases and add handling for missing information; AI answers still require judgment.

4. Are model usage and hosting included?
You provide and pay for your AI provider account and hosting. Development and testing use your API account. I configure request and output limits and document the settings so you can monitor usage.

5. What do delivery and revisions include?
You receive code, setup notes, and a working local or staging demonstration. Two revisions cover the agreed workflow. Production deployment, new workflows, extra integrations, and ongoing maintenance require separate scope.
