FAQ:
1. Can you build a new tool or add this to my existing app?
Yes. CSV mode can be a standalone React tool; API mode fits an existing React app with a working backend and access controls. The package covers one dashboard page. Send your current setup before ordering so I can confirm compatibility.

2. What data can the dashboard use?
One CSV format or one read-only API endpoint, up to 10,000 records and 20 fields. CSV processing runs in the browser. Refresh by uploading a new file or requesting updated API data. Multiple sources and complex joins need separate scope.

3. Does this include login or editing records?
The dashboard supports viewing, filtering, and exporting data. API mode reuses your existing login and permissions. New user accounts, role management, database setup, record editing, and approval workflows require separate scope.

4. Are deployment and hosting included?
Setup on one ready client-owned host is included. You provide the account, required access, and a compatible environment, and pay hosting or API fees. New infrastructure, migrations, and ongoing operation require separate scope.

5. What do the two revisions cover?
Adjustments to the agreed layout, labels, metric calculations, charts, and filters. Extra pages, sources, metrics, or new functionality need separate scope. I include the full source code and setup instructions so the tool can be extended.
