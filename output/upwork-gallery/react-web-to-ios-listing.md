## FAQs

**Does this package include Android too?**

This listing covers iOS and up to 5 existing screens. Android requires its own project configuration, signing, device checks, and scope. Send your repository and screen list before ordering so I can confirm compatibility.

**Can you convert any website or React project?**

I need source access and a working browser-buildable React app with compatible backend and login behavior. Server-rendered pages, desktop-only features, and apps without source export may need separate work. This package uses Capacitor.

**Will my app be published in the App Store?**

You receive an internal TestFlight build. Public App Store listing and submission are separate services. Apple reviews functionality, content, and policy requirements, so store acceptance is not guaranteed.

**Are push notifications, payments, or offline use included?**

New native features, push notifications, in-app purchases, offline sync, and custom plugins need separate scope. Existing web functionality is retained where compatible with the mobile platform. Internet-based features still need a connection.

**What do I own, and what do revisions cover?**

You receive the source code, platform project, build instructions, and test notes. Two revisions cover the agreed screens, navigation, and mobile behavior. Extra screens, new features, a different backend, or another platform require separate scope.
